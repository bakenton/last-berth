# Вступление и ключевые катсцены — черновик

*22.10.2026 · Никита + Claude · ЧЕРНОВИК: в игре ничего не менять (см. CLAUDE.md, «Режим „черновик“»). Тексты здесь — наброски, в лист и в код не идут.*

## 1. Поток от запуска до карты

1. **Главное меню.** Знак игры, выбор языка, «Продолжить» (если есть автосохранение), «Новая игра», «Загрузить файл». Первый клик здесь разблокирует звук в браузере, поэтому меню нужно и технически.
2. **Чёрный экран.** Включение: низкий гул, вентилятор, треск, как у старого компьютера. Звук создаётся в Web Audio, файлов не надо.
3. **Терминал загорается.** Текст бежит постепенно, идут помехи и мерцание. Помехи стихают по мере подключения систем. Пульт «просыпается» и подключает остальные системы вручную, по одной.
4. **Команды.** Терминал выдаёт состояние системы, игрок отвечает глаголом: запустить, отключить, обновить, очистить. Последняя система — Александра (модуль перевода).
5. **Катсцены (три кадра).** Комната Пульта. Вид из окна командного центра на звёздное небо. Александра показывает людям космопорт.
6. **Ныряние в карту,** дальше обычное обучение.

«Продолжить» пропускает всё, кроме меню. «Новая игра» показывает вступление. После первого прохождения предлагать пропуск по умолчанию (не решено).

## 2. Терминал: правила

- Глагол выбирается по состоянию системы. Терминал идёт по системам по очереди, игрок вводит только глагол. Объект подставляется сам.
- Неподходящий глагол получает сухой отказ в голосе Пульта. Так игрок узнаёт набор команд. Выбор косметический, последствий не обещаем.
- Клик или пробел во время печати допечатывает блок. Escape и кнопка «Пропустить» выходят совсем. На телефоне подсказка с глаголом нажимается пальцем.
- Мерцание не чаще трёх вспышек в секунду, без полноэкранных стробов. При `prefers-reduced-motion` спокойная версия. Звук необязателен: всё читается и без него.
- Всё вступление около 30–40 секунд.

Примерный список систем (набросок): воздух (очистить фильтры) · затворки космопорта (запустить) · склады (обновить учёт) · верфи (запустить) · капсулы (запустить, 128 человек) · перевод (запустить Александру).

## 3. Катсцены вступления

Соответствие старой схеме из LORE-BIBLE (раздел 2): новые три кадра заменяют четыре прежних (капсулы, зал, ангар, пульт). Прежние картинки сделаны по старому лору и в новом вступлении не используются.

| # | Кадр | Смысл |
|---|---|---|
| 1 | Комната Пульта: экраны, рабочие места | Вы здесь |
| 2 | Окно командного центра, звёздное небо над безжизненной планетой | Масштаб и одиночество |
| 3 | Космопорт, Александра показывает людям суда (поза вождя, тихая пасхалка из лора) | Начинается работа |

Порядок кадров не решён. Арт нужно делать заново.

## 4. Ключевые катсцены в ходе игры

Только на необратимых моментах. Игра на паузе, пропуск доступен, увиденное попадает в хронику Александры.

| Момент | Что меняется | Тон |
|---|---|---|
| Первые суда нового поколения (поколение II) | Игра растёт | Пульт сухо, Александра с лёгкой иронией |
| Пульт называет дату ковчега | Начинается отсчёт | Пульт цифрами, Александра тихо, без иронии |
| Первый экипаж отказывается лететь | Страх заметен | Александра, без иронии |

- Показывать **отказ**, а не мятеж: по лору (раздел 6) это не мятеж. Слово «бунт» игроку не показывать.
- Дата остаётся в интерфейсе. Катсцену можно пропустить, а дата самая важная информация.
- Только первое новое поколение. Остальные идут уведомлениями.

## 5. Зависимости и риски

- Слово вместо «Ночи» (кандидаты в лоре: «Порог», «Срок», «Отсечка») нужно выбрать до текста катсцены с датой.
- Арт для трёх кадров вступления и трёх ключевых катсцен.
- Звук: гул нельзя включать до первого клика. Нужен способ выключить звук.
- Не проверено в коде: точки срабатывания (`G.gen`, `mutinyForecast`, `nightSeen`), очередь `tutPush`/`tutNext`, взаимодействие с голосом Александры (`NAR`, `f:'V'`), механика автосохранения для «Продолжить» (в коде есть `autosave`, ключ `lb.save`).
- Тексты `nar_*` и кадры вступления в игре пока по старому лору.
