# LAST BERTH — музыка (черновик 22.10.2026)

Статус: решение Никиты 22.10 — генеративный слой, привязанный к состоянию игры. Промпты ниже **не прогонялись** (проверить на первом стеме). Код не написан.

## Карточка (ворота «новая механика», в объёме отклика)
- **Желание игрока.** Чувство долгого, одинокого, но осмысленного дела. Музыка не подсказывает действий.
- **Что накапливается.** Голоса: чем больше миров заселено (`settledCount(G)`), тем больше инструментов в ансамбле. Колония слышна.
- **Решение игрока.** Никакого. Музыка не меняет правил — только отклик. Баланс и боты не затронуты.
- **Чем отличается от жанра.** Eno-приём (петли разной длины, повтор не слышен) + привязка к охвату вместо смены трека по ситуации.

## Принципы
1. Одна тональность на все стемы: **D минор / дорийский**. Тогда любые слои звучат вместе в любой момент.
2. Без ритма, без вокала, без темпа. Темп на скорости 10× не меняется — раскрывается фильтр.
3. Каждый стем — своя длина (90 / 70 / 60 / 80 / 66 с), петли сдвигаются друг относительно друга. Стык — кроссфейд ~8 с в движке (на пэдах не слышен).
4. Музыка по умолчанию тихая (~−20 дБ от звуков интерфейса), отдельный переключатель, стартует только после первого жеста (разблокировка уже есть в `SFX`).
5. Звуки интерфейса переделать под музыку: сейчас square/sawtooth в `ui.js:263` — на мягком пэде режут слух. Перевести на sine/triangle с мягкой атакой, отдельная правка.

Тревоги (еда и т. п.) — только звуки интерфейса, не музыка.

## Модель
Стоит `ace_step_1.5_turbo_aio.safetensors`, шаблон ComfyUI `audio_ace_step_1_5_checkpoint` (ACE-Step 1.5 AIO). Видеокарта RX 6700 XT, 12 ГБ — достаточно. Turbo-версия почти не слушает отрицания (CFG низкий), поэтому «no drums» пишем утвердительно в теги и проверяем на слух.

Параметры в шаблоне (проверить имена полей через `list_workflow_slots`):
- keyscale: `D minor`, bpm: 60 (для пэдов не имеет значения), time signature: 4.
- lyrics: `[Instrumental]`
- seconds: из таблицы выше.
- seed: брать 4 сида на стем, оставлять лучший.

## Что делать по шагам
1. Один пробный стем (`bed`, 4 сида). Слушаем: нет ли ударных, вокала, дрейфа высоты, провалов громкости. Если нет — правим теги и идём дальше.
2. Если просочились ударные — прогнать через шаблон `utility-audioseparation`, взять дорожку `other`.
3. Остальные стемы по таблице. Отбор на слух: должны складываться друг с другом, а не спорить.
4. Постобработка: нормализация к одному уровню, обрезка тишины по краям, mono/stereo и битрейт. Оценка: 7 стемов × ~75 с при 48–64 кбит/с ≈ 2–4 МБ, в base64 ×1.33. Safari не любит ogg/opus — решаем на сборке (mp3 безопаснее).
5. Движок `MUSIC` в `ui.js` рядом с `SFX`: загрузка стемов из сборки, цикл с кроссфейдом, плавные громкости по состоянию, переключатель + тексты (в `work/new-texts.tsv`), `tools/build.py` вшивает файлы.
6. Проверка: проверяем структуру (состояние слоёв и значения громкостей по состоянию игры) — на слух проверяет только Никита.
7. Пересобрать звуки интерфейса под мягкий тембр.

## Что узнали про железо (RX 6700 XT, ROCm)
- Декодер звука ACE-Step падает целиком (весь ComfyUI), если декодировать длинный клип одним куском: ядро MIOpen выходит за 32-битный предел. На 90 с падает, на 80 с тоже (нехватка видеопамяти). **Лечение:** в шаблоне заменить `VAE Decode Audio` на `VAE Decode Audio (Tiled)` (tile 512, overlap 64). После этого 80 с идёт без падений, около 1,5 мин на сид.
- ComfyUI Desktop слушает порт 8188, сборка в `E:\ClaudeCowork\ComfyuUI\ComfyUI` по `start-comfyui.cmd` — 8189. Когда Desktop закрыт, `comfy launch` запускает сборку на 8188.
- `run_workflow` иногда отвечает ошибкой на отправке — повтор проходит.

## Риски
- Вес файла: 3–6 МБ в одном HTML для пересылки. Если неприемлемо — меньше стемов или mono/ниже битрейт.
- Генерация пэдов может «плыть» по высоте внутри клипа — слышно при стыке петель. Лечится отбором сидов и коротким клипом.
- Лицензия: условия использования ACE-Step проверить до публичного релиза (для тестеров неважно).
