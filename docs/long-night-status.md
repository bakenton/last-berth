## Рабочая схема

- Правка: `core.js` / `ui.js` на месте (Python read-modify-write с `assert s.count(old)==1`). Новые тексты → `new-texts.tsv`, изменённые → `changed-texts.tsv` (`table\tkey\ten\tru`). `python3 build.py` → `page.html` / `long-night.html` / `artifact.html`. Публикуется `artifact.html`, скопированный поверх `index.html` в папке Artifact read.
- **build.py собирает из live.html (=артефакт).** Если артефакт опубликован с новыми текстами, а `new-texts.tsv` потом перезаписан — они выпадут. Перед публикацией сверять число строк (`rows N`).
- Текстов в коде нет: `<script type="application/json" id="lb-texts">`. Плейсхолдер `{g}` → римская цифра; `{t}` в `kit_*` строках тоже римская.
- Боты: `node sim.js core.js 3500` (8 сидов). A/B против `core-old.js`. `DUMP=<seed> node sim.js core.js 3500 <seed>` → JSON прогона pro в `/tmp/dump.json`.
- Регресс перед публикацией: pw9, pw15, pw16 (мигает 1 из 4 — таймаут `#prev`, было и на v4.2), pw17, pw18, pw19 (16/16), pw20, pw21 (17/17), pw22 (17/17), pw23 (24/24), pw24 (43/43) + боты. Все браузерные сценарии после `data-lang` жмут `data-act="oskip"` (вступление).
- Playwright — настоящей мышью. «Работает» только после прогона.
- Никите — пошаговые инструкции с названиями кнопок; файлы — в чат.

## Что это

Менеджер межзвёздной колонизации, стратегия + айдл. Игрок — пульт Института на Земле, смены по 80 лет. Колонии со специализацией, линии мир↔Земля ходят сами, люди — третья валюта. Лор конца: коллапс региона, дата открывается на третьем секторе (или к году 1000), дальше **3300** лет. Ковчег уходит только на двигателе ≥ отметки в день даты **+2**; счёт — проснувшиеся. Голод 260 лет — проигрыш раньше.
