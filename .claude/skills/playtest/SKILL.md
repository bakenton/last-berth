Бот ловит механику, а не ощущение: ошибки страницы, утечки текста (`undefined`, `{x}`, `NaN`), обрезку и выход за край, перекрытые кнопки, потерянные нажатия, отказы кнопок с причиной, мёртвые часы, частоту больших окон, «нечего делать». Интерфейс v4.35: карта + 6 вкладок, окно мира, советник; бот играет мышью. Ощущение — по скриншотам и журналу в отчёте.

1. Сборка свежая: `cd work && py -3 ../tools/build.py` (или `bash tools/regress.sh smoke`).
2. Прогон (из корня):
   - `node tools/playtest.js --minutes 3` — чистое время игрока, ~700–900 лет на ×10.
   - `node tools/playtest.js --minutes 3 --god` — с промоткой GOD.skip (панель отладки в каждой сборке с v4.40): пустые отрезки промотаны, доходит до Ночи и ковчега. В отчёте помечено — это не темп игрока.
   - `--god`: между решениями бота время мотается GOD.skip (15 лет после действия, 100 после пустого круга, перед Ночью — длиннее, чтобы Ночь легла в бюджет минут). Не темп игрока; в отчёте помечено. Бот-фермер слабый: без `--rich` Земля иногда голодает до Ночи (это итог `lose`, не баг интерфейса).
   - `--rich` (только с `--god`): GOD.res подкармливает Землю и добивает ресурсы ковчега и конвоя — чтобы дойти до отплытия ковчега и проверить Ark/Yard-экраны.
   - `--skip` (без `--god`): когда делать нечего, жмёт настоящую кнопку SKIP.
   - `--viewport 390x844` — телефон (интерфейс масштабируется целиком, цели мелкие); `--seed N`; `--shots` — скриншот каждые 300 лет.
   - `--brain sim --style rush|serial|ark|bank` — решения принимает голова бота ядра (`tools/sim.js` step()) через API ядра, не кликами; большие окна закрываются мышью, аудит идёт.
   - `--style serial|rush` — линий на мир 2 / 4 вместо 3, ковчег уровнем 2 / вабанк.
3. Результат: `work/playtest/<метка>/report.md` + `events.json` + `game-log.json` (для агента `balance`) + `shots/`. Код выхода 1 = есть crit.
4. Разбор: каждую строку «Найденное» перепроверь по скриншоту — бот ошибается (перекрытие из-за собственного клика, подписи-глифы). Никите — только подтверждённое, цифрами: год, что видно, скриншот.
5. Отчёт в `work/playtest/` в git не идёт (`.gitignore`); подтверждённые находки — карточки F-NN в Notion.
