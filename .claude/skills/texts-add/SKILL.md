Ни одной строки игрового текста в коде (CLAUDE.md). Игра на английском, RU — в таблице.

**Добавить / изменить строку**
1. Формат: `work/new-texts.tsv` (новые) и `work/changed-texts.tsv` (изменённые) — по строке на ключ, **табами, без заголовка**: `table⇥key⇥en⇥ru`. Таблицы: `UI` (интерфейс, `T('key')`), `LOG` (журнал), `MSG` (отказы кнопок и сообщения, `say('code')`), `RES`, `GUIDE`, `VOICE`.
2. Плейсхолдеры `{x}` в EN и RU одинаковые. Новый код отказа `off(code,params)` = новая строка MSG с этим кодом.
3. Ключи не клади в динамические имена без нужды (`'lobe'+n`, `'endNightB'+tier` проверке по литералу не видны).
4. `cd work && py -3 ../tools/build.py` → печатает rows · added · changed. Затем `node tools/texts-check.js` (паритет, дубли, ключи в коде, круговой тест) и `bash tools/regress.sh smoke`.
5. Увидь строку в игре глазами (браузер, EN и RU) — «работает» только так.

**CSV для Никиты**
6. `node tools/texts-csv.js "<где, напр. v4.25 ark>"` → `texts/texts-vX.YY-append.csv` (без заголовка, `status=live`, note `new`/`changed`). Берёт только строки, которых нет в tsv коммита `HEAD`; если tsv уже закоммичены в этой итерации — `--since=<коммит до итерации>`. Сверь число строк с тем, что добавил в tsv. В tsv старые строки не удаляются — не пугайся длинных файлов.
7. Сам допиши строки в лист: spreadsheet `1q41e1HBxS1tsZB4beTVOcdUGzi_fIQHDHc3xp58lg-I`, вкладка `Untitled`. Загрузи инструмент `append_values` через ToolSearch (`select:mcp__817dda05-476f-41cd-996f-e47e666b0307__append_values`), один вызов: `range` = `Untitled!A1`, `values` = строки CSV как массивы из 7 ячеек (table,key,en,ru,where,status,note). Лист целиком не читай. Строки новых ключей — note `new`, правленых — `changed`. Последняя live-строка с ключом побеждает. Номера строк — из `updatedRange` ответа.

**После записи в лист** (если Никита импортировал сам — спроси номера строк):
8. HANDOFF.md, строка «Тексты»: «все в листе (строки до B)». ≤20 строк в файле.
9. Коммит `vX.YY: texts imported (rows A-B)`.

Известная неясность: заголовок в CSV — в CLAUDE.md «без заголовка», но v4.22 и v4.24 лежат с заголовком и импортировались. Генератор пишет без; если лист показал строку-заголовок среди данных — скажи Никите удалить её.
