## v5.08 · 09.11.2026 · 3D-карта на WebGL

Никита 09.11: в Chrome на Android-планшете 2–4 к/с, «при поворотах лагает нереально даже при старом свечении», «Так может дело в html?» → «Переводи. Я не хочу костыли с проблемами».
- **Почему лагало.** Диагностика на планшете (`tools/diag-map.js` → `play/DIAG-map.html`, вне git): `chrome://gpu` — холст на видеокарте; лаги уходили с «без свечения» и «холст 50%»; без поворота после v5.07 — 59 к/с, при повороте — лаги. Canvas 2D отдавал видеокарте отдельную команду на каждую линию, гекс и тень (тысячи за кадр, каждая тень — свой проход по холсту), при повороте всё это заново каждый кадр.
- **Что сделано.** Отрисовка карты переведена на WebGL (без библиотек, WebGL1). Сцена — тот же код и тот же порядок, но рисует в рекордеры `M3R` (часть интерфейса Canvas 2D), которые превращают её в треугольники:
  - линия — полоса со скосом в стыках и мягким краем 1 px, заливка — веер, пунктир режется по пути; кадр — несколько вызовов отрисовки;
  - ~1000 гексов строятся один раз и проецируются видеокартой;
  - свечение — треугольники светящихся линий в буфер половинного размера, сложение (как складывались тени Canvas), размытие по Гауссу с весами с процессора, 4 размера как у прежних теней (4, 6, 8–10, 12–14); только в прямоугольнике, где оно есть;
  - космос — текстуры, один проход;
  - пока камера стоит, космос с полом и следы с линиями (с их свечением) запечены в текстуры и кладутся одним прямоугольником; при движении рисуются прямо в кадр.
- Знаки «×» брошенного мира и «?» пропавшего судна — в SVG поверх карты (WebGL не рисует буквы).
- Без WebGL холста карты нет (имена и тревоги на SVG остаются). Запасного Canvas 2D нет — решение Claude, один путь отрисовки.
- До WebGL в этой же версии (коммит раньше): поворот дешевле без смены вида — гексы без разбора строк цвета, SVG поверх карты обновляет координаты на месте и раз в кадр, размер карты через `ResizeObserver`.
- Сверка: скриншоты рядом с v5.05 в один момент времени — на глаз то же (свечение подогнано сложением теней). Попиксельно не совпадает: другой способ сглаживания и размытия.
- Замер (Chromium с видеокартой, процессор ×4, палец 120 Гц, поворот): v5.07 37–44 к/с, основной поток занят на 97–99%; v5.08 45–60 к/с. Программный WebGL (SwiftShader, без видеокарты): ~13 к/с на 2196×1440 — медленнее Canvas 2D; на устройствах без видеокарты карта будет тяжелее, чем была.
- Не проверено: планшет Никиты, слабые телефоны, потеря контекста WebGL (обработчик есть, руками не вызывался).
